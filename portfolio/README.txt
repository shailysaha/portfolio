SHAILY PORTFOLIO — LAVENDER & PEACH REDESIGN

HOW TO INSTALL

1. Make a backup copy of your current portfolio folder.
2. Copy index.html into your portfolio root folder.
3. Copy css/style.css and css/responsive.css into your css folder.
4. Copy js/script.js into your js folder.
5. Keep your existing images folder unchanged.
6. Open index.html with Live Server and press Ctrl + F5.
